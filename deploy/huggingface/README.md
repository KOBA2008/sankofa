# SANKOFA backend

API of [SANKOFA](https://github.com/KOBA2008/sankofa): the place agent, country chronicles,
documentaries and archive corpus. Built for the Meta Global AI Developer Hackathon 2026.

Secrets to set in the Space settings: `META_API_KEY` (Meta Model API) and optionally
`BASETEN_API_KEY` (Muse Spark open). `DAILY_PAID_CALL_LIMIT` caps paid AI calls per day.
